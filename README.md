# Disaster Relief & Supply Chain Allocation Engine

## Project Overview
The **Disaster Relief & Supply Chain Allocation Engine** is an automated Java management application built to coordinate logistics and emergency supply triage during natural disasters. 
By utilizing priority-queue data structures and object-oriented architectural patterns, the system matches limited central warehouse inventory 
(Medical, Food, Water, Shelter) to field relief camps based on urgency tiers, producing transparent dispatch manifests and eliminating logistical bottlenecks.

## Features
- **Deterministic Triage Queuing:** Evaluates camp demands via a custom `PriorityQueue` utilizing urgency weights (`CRITICAL` > `HIGH` > `MEDIUM` > `LOW`).
- **Inventory Lifecycle Management:** Categorizes stock items, tracks real-time quantities, and prevents inventory over-allocation.
- **Interactive Data Ingestion:** Add supplies and lodge camp demands dynamically via GUI dialog modals.
- **Dual-Pane Operations Dashboard:** Clean Java Swing GUI displaying active inventory levels alongside live camp distress requests.
- **Live Dispatch Ledger:** Displays timestamped fulfillment logs as allocation operations execute.
- **CSV Manifest Generation:** Exports delivery records directly to `dispatch_manifest.csv` for transport drivers and administrative audits.

## Technologies & Tools Used
- **Language:** Java SE 17 or higher
- **GUI Framework:** Java Swing (`javax.swing.*`, `java.awt.*`)
- **Data Structures:** Custom Java Collections Framework (`PriorityQueue`, `LinkedHashMap`, `ArrayList`, `Comparable`)
- **IDE / Environment:** Visual Studio Code with Extension Pack for Java
- **Version Control:** Git & GitHub

- Java Development Kit (JDK 17 or later) installed on your machine.
- Visual Studio Code installed with the **Extension Pack for Java** enabled.
